# Bowles Hall website

A redesign of the [bowleshall.org](https://www.bowleshall.org/) home page as a static site for GitHub Pages.
No build step: `index.html`, `styles.css` and `assets/`.

Preview locally:

```bash
python3 -m http.server 8000
```

Photos and the crest are taken from bowleshall.org. Inner-page links still point to the original site.
